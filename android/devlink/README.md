# MGU DevLink

App Android (Java thuần) để làm việc với đầu xe qua SSH mà không cần máy tính:
dán lệnh và chạy, sao chép kết quả, quét thông tin máy, tải/gửi tệp (qua cat/tar, không cần SFTP).

Build bằng GitHub Actions (`.github/workflows/devlink.yml`), APK nằm ở mục Releases.
Keystore `app/devlink.jks` được commit để các bản cài đè lên nhau được.
